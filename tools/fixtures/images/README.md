Image decoder fixtures created for SrvrOS tests; no external artwork.

- `pattern.png`, `.bmp`, `.jpg`: 19×13 synthetic color/alpha pattern, encoded
  with Pillow (JPEG quality 95). The decoder test checks exact PNG/BMP pixels
  and the pinned original JPEG decoder's output checksum.
- `large.png`: 1600×1000 grid generated by `tools/image_fixtures.py`; exercises
  mapped decode allocations and native Preview fit/zoom/pan.
